# SOC Labs (Blue Team Portfolio)

This repository contains my hands-on SOC / Blue Team home lab projects focused on log analysis, alert triage, and incident-style documentation.

## Projects

- **Project 1 – Brute Force Detection Using Windows Security Logs**  
  Detecting repeated failed logons (Event ID 4625) and correlating successful logons (Event ID 4624).  
  📂 Folder: [project1-bruteforce-windows-logs](./project1-bruteforce-windows-logs)
  
- **Project 2 – Port Scan Detection Using Wireshark (SYN Scan)**  
  Simulated reconnaissance activity using Nmap and detected SYN scan patterns in Wireshark using TCP flag filtering.  
  📂 Folder: [project2-portscan-wireshark](./project2-portscan-wireshark)

- **Project 3 – Phishing Email Analysis (IOC Extraction)**  
  Analyzed a suspicious phishing email and extracted key IOCs (sender/domain/IP/URL) using Gmail “Show original” with evidence screenshots.  
  📂 Folder: [project3-phishing-email-analysis](./project3-phishing-email-analysis)
